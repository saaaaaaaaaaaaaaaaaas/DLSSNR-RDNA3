NR Control: Ditto Relight 0.5.4 local update (Linux/Proton x86_64 RDNA3)

Requires an existing RDNA3 0.0.9 installation and the OptiScaler route.
Exit the game. Back up OptiScaler/plugins/dlssnr-amd.asi and the entire
existing dlssnr-amd/shaders/renodx folder outside the game folder.
Merge this archive's OptiScaler and dlssnr-amd folders into the game folder.
Replace the ASI and ALL included Ditto/Relight shaders and notices together.
Keep your installed model files, OptiScaler and preferred SR/FG provider.

NR Control (End), RenoDX layer:
  Placement: Before the upscaler
  Upsampling: Ditto Relight (saved selection 4)
  Resolution scale: 0.25 to 1; disable Follow render resolution
  Ditto Relight: Lighting, Ambient occlusion, Global illumination, Samples

At 1280x720 and 0.33, the model uses 422x238. A guided neural edit is
reconstructed onto the original 1280x720 reference before OptiScaler's SR.
Lighting uses full-size guides and half-size AO/GI, independent of model size.
At scale 1, NR needs no enlargement; lighting still works.
Lighting off retains guided reconstruction without the extra AO/GI and curve.
The game's readable depth, motion vectors and jitter are required.

The NR interface does not provide projection metadata. Set Vertical FOV and
Near/Far plane to the game camera if the default 60 degrees / 0.1 / 100000
does not match. Lighting is experimental screen-space AO/GI.
Motion/API checks on Z1 Extreme pass. Real-game HDR/PQ, FG and cascaded SR
quality remain unqualified. No model or NVIDIA DLL is included.

Rollback: exit the game and restore the backed-up ASI and shader folder.
