Experimental ReShade -> OptiScaler -> FSR3 FG bridge for Linux / Proton

Development payload for DX11/DX10 through DXVK, x86_64, SDR, 2x FG.
See manifest.json for the exact producer/consumer revision and file hashes.
This payload contains no NVIDIA files, models, LumeniteFX or runtime dependencies.

Extract source/DLSSNR-RDNA3-source.tar.gz into a new project directory.
Read linux/optifg/README.md and docs/RESHADE-OPTIFG.md for build instructions,
observed tests and unqualified behavior. fetch_deps.sh retrieves pinned runtimes.
LumeniteFX is obtained directly from its author's link by the probe runner;
its shaders must not be included in redistributed bundles.

For the standalone probe, copy bin/OptiScaler.dll into artifacts/optifg-consumer/
and bin/dlssnr_amd.addon64 into artifacts/package-build/nr/ in that source tree.
Set NR_PROTON and follow the baseline/direct/reshade commands in the README.
The runner builds the probes locally; bin/ also carries the matching CI probes.
Begin with NR disabled and explicit camera values for the test scene.

The consumer is GPL-3.0-or-later. Its corresponding source is OptiScaler commit
e7e3872d410f704479d94d318d68d163b6b58947 from
https://github.com/optiscaler/OptiScaler (including its pinned submodules), plus
linux/optifg/optiscaler.patch and receiver/ from the enclosed source archive.
prepare_optiscaler.py and .github/workflows/optifg.yml reproduce that build.
Keep these source files, build instructions and licences with redistributed DLLs.
